Frequently asked questions

Why does my browser or Windows SmartScreen show a warning?

Ada is new and not yet code-signed, so browsers and SmartScreen show a standard reputation warning — not a virus detection. Verify the download with SHA-256 against SHA256SUMS.txt, then choose “More info → Run anyway”.

Where does my data go?

Everything stays local in %APPDATA%\Ada with zero telemetry. Only weather (MET Norway, location by IP) and synced lyrics (LRCLIB) are fetched when enabled.

How do I uninstall Ada?

Uninstall anytime from Settings › Apps, with an optional prompt to remove your local data. For the portable ada.exe, simply delete the file.

Is there a macOS or Linux version?

Windows only — the notch idea comes from Mac, and Ada brings it natively to Windows 10 and 11.
